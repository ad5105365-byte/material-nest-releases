# 素材小窝 1.0.1 测试版

本测试版仅供作者邀请的亲友个人测试。未经作者书面同意，请勿转卖、公开转发安装包或修改版、改名冒充或商业分发；转发给新测试者前请先征得作者同意。版权署名：叮咚。完整许可见安装目录中的“软件版权与测试许可.txt”。

给有很多 PSD / PSB 素材的朋友试用：Windows 10/11 64 位，双击安装，不需要 Python，也不需要 GitHub 帐号。每个人原有的文件夹结构可以不同，不必重新整理。

安装软件本身预留几分钟；首次扫描另算，先选 30–50 个文件的小文件夹试跑，再逐步扩大。安装时可以开 PS，先保存文件；扫描可能占用 CPU、内存和磁盘，处理大文件时电脑可能变慢，不建议同时在 PS 批量开大文件。扫描期间不要移动、覆盖保存正在扫描的素材或拔掉硬盘。

它按本机文件和图层信息建立索引，扫描不需要启动 Photoshop；“PS 打开”需要自己的 Photoshop。私人数据保存在本机，不上传、不与其他人同步。购买台账是可选测试功能，待整理线索尚未开放。

软件会检查新版并提示，到设置点击后再下载和安装；接收者不用 GitHub 帐号。在线更新失败时，我也可以直接发新安装包，覆盖安装即可，不用先卸载。

遇到问题请发操作步骤、提示和日志，注意遮住个人路径即可，不用发 PSD 素材。详细操作见安装包内的“安装使用教程”。


新版发布后软件会在启动及使用期间检查，并提示用户点击安装；也可以到设置手动检查更新。在线失败时可直接接收新版安装包并覆盖安装，不必先卸载。
